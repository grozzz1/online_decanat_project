В пробе `separate_dates` модель предложила `0109-20-24` и `3006-20-28`. Программа отклонила обе некорректные даты и оставила null. Это безопасный отказ принять значение, **но не успешное восстановление**. Результат сохранён; повторений ради удачного ответа не было. Скрипт проб теперь возвращает ненулевой код при несовпадении ожидаемых результатов, вместо безусловного exit 0.

В основной PNG-выборке Regex и гибрид одинаковы: 279/280 полей. Пропущенные значения действительно отсутствовали; Qwen не повысила accuracy. Рабочий QA ответил на все 120 вопросов без модели, поэтому 100% не являются оценкой генеративных возможностей Qwen. Результаты синтетической выборки не переносятся автоматически на реальные документы.

Python Launcher `py -3.12` на этой машине не обнаружил установку; прямой путь `%LOCALAPPDATA%/Programs/Python/Python312/python.exe` работает. В README есть этот вариант. В проверенной переносной установке Tesseract нет `osd`; без него автоматическая ориентация может быть недоступна, обработка продолжается с предупреждением.

CI настроен на Windows/Python 3.12 с закреплёнными ревизиями официальных [checkout v7.0.1](https://github.com/actions/checkout/releases/tag/v7.0.1) и [setup-python v7.0.0](https://github.com/actions/setup-python/releases/tag/v7.0.0). Статус удалённого запуска доступен в [GitHub Actions](https://github.com/grozzz1/online_decanat_project/actions). Загрузка Qwen и настоящая отправка сообщений в CI не выполняются.

Журналы, полные предсказания и исходники отдельной копии проверки находятся локально в `.tmp/` и `benchmark_results/`; они исключены из Git.
