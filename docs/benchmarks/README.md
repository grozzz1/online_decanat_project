# Измерения на учебной выборке

Полный реальный прогон: **30 синтетических документов, 120 вопросов для каждого QA-варианта**. Набор использовался при разработке; это не независимая оценка реальных студенческих документов. PNG/PDF — представления одних документов, а не 60 независимых примеров.

## Извлечение полей

| Подход | Правильно | Micro accuracy | Среднее, с/документ | Документов с LLM | Восстановлено |
|---|---|---|---|---|---|
| regex | 279/280 | 99.64% | 1.984 | 0 | 0 |
| hybrid | 279/280 | 99.64% | 7.599 | 17 | 0 |

Один оставшийся PNG-конфликт — латинские/кириллические символы номера `open-009`. Fallback для отсутствующих полей сохраняет уже найденный номер. Если поле действительно пусто, null является правильным результатом. Нулевое число восстановлений не означает улучшения точности.

## Ответы

| Подход | Exact QA | Среднее, с/вопрос | LLM-запросов | Ложные отказы | Технические ошибки |
|---|---|---|---|---|---|
| qwen_baseline | 34/120 (28.33%) | 20.1713 | 30 | 1 | 0 |
| qwen_strict | 39/120 (32.50%) | 21.8906 | 30 | 24 | 0 |
| python_rag_qwen | 120/120 (100.00%) | 0.0016 | 0 | 0 | 0 |

Exact QA сравнивает **answerable, value и множество sources**. Смысл каждого предложения свободного ответа автоматически не доказан. Два генеративных варианта оценены по сырым ответам; пользователю такие ответы без проверки не выдаются. Baseline — заново определённый простой промпт, не историческая версия Qwen. Время генеративного QA амортизировано: пакет из четырёх вопросов делится на четыре. Это не задержка одиночного вопроса.

Варианты, не прошедшие официальный формат: qwen_baseline, qwen_strict. Для них Exact QA выше является диагностической метрикой собственного постобработчика, не официальным баллом. Например, корректная JSON-строка `VALIDATION.missing_fields` не является допустимой ссылкой `field:*` или `rule:*`. Сырые ответы не исправлялись для оценки.

Столбец hallucinations учитывает выявленные ошибки фактического value и необоснованные ответы. Ошибки формата статуса вынесены в validation_format_errors. Полная ручная разметка каждого утверждения свободного текста не выполнялась.

Если гибрид отвечает без LLM на всех вопросах набора, его QA-оценка проверяет Python и правила, а не качество сложной генерации Qwen. Отдельные синтетические реальные пробы модели описаны в локальном полном отчёте; они использовались при разработке и не добавлены к accuracy.

Отдельные реальные пробы после рефакторинга: 5/6 целевых результатов. Неуспешные сценарии: separate_dates. Отказ принять неверное значение не считается успешным восстановлением. Результаты сохранены; повторы для получения зелёного результата не выполнялись.

## Воспроизводимость и границы

Протокол измерения зафиксирован в коммите `b3d3587` до организационного рефакторинга. Промпты и алгоритм не менялись во время генерации. Последующие перенос чистых правил, исправление импортов и форматирование проверены регрессионными тестами; времена относятся к измеренному протоколу.

Windows, Intel Core i5-1135G7, около 16 ГБ RAM; CPU llama.cpp `b11429`, 4 потока, один слот, контекст 4096; температура 0, seed 42, no thinking. Сервер сохранял веса между запросами. Отдельные пробы Vulkan не включены в эти метрики.

Модель: `unsloth/Qwen3-4B-Instruct-2507-GGUF`, ревизия `a06e946bb6b655725eafa393f4a9745d460374c9`, `Qwen3-4B-Instruct-2507-Q4_K_M.gguf`. SHA256: `3605803b982cb64aead44f6c1b2ae36e3acdb41d8e46c8a94c6533bc4c67e597`.

Предыдущая проверка CV до интеграции AI: PNG 279/280, PDF 280/280, классификация и комплектность 30/30, QA 120/120. Это те же документы и другие условия запуска; сравнивать времена как ускорение нельзя.

В Git включены только агрегаты. Полные документы, OCR, значения, ответы модели, сравнения с эталоном и временные GPU-пробы остаются локально в `benchmark_results/`. Там же находятся семь запрошенных CSV, сырой `inference_performance.csv`, полный `report.md` и журналы официального оценщика. [Команды воспроизведения](../../README.md#воспроизведение-бенчмарков).

Проценты не доказывают подлинность подписи, правомерность решения и отсутствие галлюцинаций на произвольных вопросах. Новые правила, реальные фото и другие макеты требуют собственной проверки.
